# Findings (Step 0)

1. Screens are `.panel` blocks (`#panel-home`, `-setup`, `-ai`, `-dashboard`, `-scholarship`, `-about`, `-faq`) inside `#main`. `goStep(step)` in `core/state-nav.js` sets `APP.currentStep`, toggles `.panel.active` and `.step-item.active` (matched by `data-step`), then runs step-specific code.
2. `#stepper` is a fixed, horizontally scrolling `<nav>` under `#topbar`. Layout offsets are hard-coded in `--content-top` (96px, 90px, 86px in media queries), so a third fixed bar was rejected as too risky.
3. Nav clicks use one delegated listener: `data-action` + `data-arg` in `ui/common/inline-actions.js`. Clicking Home (`goStep home` via that dispatcher) does `location.reload()`.
4. Lazy-load pattern already used: `goStep('scholarship')` does `await import('../ui/scholarship/scholarship-nav.js')`. Explore copies it.
5. Upward calls go through `core/ports.js` (`port` / `provide`). The cycle checker reads only static imports; dynamic `import()` must still resolve.
6. Settings live in `localStorage` under small keys (`si-theme-choice`, recent files, seen flags), each in `try/catch`. Student data is never stored. Explore prefs follow this style.
7. i18n: shards `i18n/<feature>/<lang>.json`; `core/render-i18n.js` merges the shards listed in `I18N_FEATURES` into `window.I18N_TABLES`. `SR_STRINGS_EN` (inline English mirror, regenerated by `scripts/sync-sr-strings-en.py`) is the fallback inside `srT()` for every language.
8. `scripts/i18n-gap-check.py` compares only three groups (main, onboarding, smart-plan) against 12 locales. A new `i18n/explore/en.json` outside those groups does not trip it, which fits the "English only" rule.
9. `scripts/gen-sw-precache.py` globs ALL `css/*.css`, `core|ui|bal|dal/**/*.js` and `i18n/*/en.json` into `SHELL_ASSETS`. It must be taught to skip Explore files, otherwise Insight-only users download them at install.
10. `sw.js` fetch handler: CDN cache-first; `.xlsx` network only; same-origin network-first with cache fallback. `activate` deletes every cache not named `CACHE_NAME`.
11. CSP is `connect-src 'self' ...`, so same-origin `data/explore/*.json` fetches are allowed. External links are plain navigation and need no CSP change.
12. There is NO state list in the app (only countries in `i18n-countries/index.json` and per-country languages in `core/shared-constants.js`). Assumption recorded in HANDOVER: the State picker is derived from the `states` values present in loaded feed data, never hand-listed.
13. `core/env-config.js` detects QA by hostname containing `sandeephakki-qa`; README already lists a QA site `https://sandeephakki-qa.github.io/student-insight/`.
14. No browser is available in this chat (no Chromium, no Playwright download host). UI checks are Node/jsdom only.
